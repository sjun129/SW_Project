# 자취실록 앱 (Expo SDK 57)

세입자가 입주·거주·퇴거 시점의 방 상태를 위변조할 수 없는 기록으로 남기고, 임대인 확인과 퇴거 비교 리포트까지 이어 주는 앱의 프로토타입입니다. 디자인은 Figma "v2 · 자유 탐색 구조" 섹션(`../design-refs/`)을 따릅니다.

## 실행

```bash
npm install
npx expo start
```

- 휴대폰: 스토어의 Expo Go(SDK 57 지원 버전)로 터미널의 QR 코드를 찍으면 됩니다.
- 웹: `npx expo start --web` 또는 `npx expo export --platform web` 후 `dist/`를 정적 서버로 엽니다.
- 검사: `npx tsc --noEmit`, `npx expo lint`

## Supabase 연결

1. Supabase 대시보드의 SQL Editor에서 `../supabase/migrations/`의 SQL 파일을 이름 순서대로 한 번씩 실행합니다 (`init` → `landlord_verify_events` → `landlord_guard` → `realtime_events`).
   AI 기능을 쓰려면 `npx supabase functions deploy vision --project-ref <ref>`로 Edge Function을 배포하고, 대시보드의 Edge Functions → Secrets에 `OPENAI_API_KEY`를 넣습니다(모델은 `OPENAI_MODEL`로 바꿀 수 있습니다).
2. `.env.example`을 `.env.local`로 복사하고 프로젝트 URL과 **publishable(anon) 키**를 넣습니다. service_role 키는 절대 넣지 않습니다.
3. 개발 서버를 다시 시작합니다(`npx expo start --clear`).

- 이메일로 가입·로그인하면 집, 구역, 사진(원본은 `originals` 버킷), 하자, 임대인 확인, 하자 신고, 리포트가 서버에 저장됩니다.
- 서버 수신 시각과 해시 체인은 DB 트리거가 계산하고, 원본 사진과 사진 기록은 수정·삭제할 수 없습니다.
- "로그인 없이 둘러보기"는 서버를 쓰지 않는 데모 데이터입니다.
- 알림과 최근 활동은 `events` 테이블에 저장되고, 임대인의 열람·확인·이의는 서버 트리거가 알림으로 남깁니다.
- 임대인 링크는 `/c/<token>` 웹 페이지입니다. 웹 빌드를 호스팅한 뒤 `.env.local`에 `EXPO_PUBLIC_WEB_URL`을 넣으면 공유 메시지의 링크가 그 주소로 바뀝니다.

## 추가 기능

| 기능 | 위치 |
|---|---|
| 입주 확인서·리포트 PDF 저장/공유 (FR-08, FR-17) | 확인서 "PDF 저장", 리포트 발급 후 "PDF 공유" (웹은 인쇄 창 → PDF로 저장) |
| 임대인에게 보내기: 카카오톡(시스템 공유), 문자, 링크 복사 (FR-09) | 확인서 → 임대인에게 보내기 |
| 임대인 확인 페이지, 7일 만료 사진 링크 (FR-09, FR-10) | `/c/<token>` |
| 퇴거 촬영 시 입주 사진 반투명 오버레이 (FR-14) | 카메라, 퇴거 기록 |
| 퇴거 단독 리포트 통상 손모 체크리스트 (FR-20) | 리포트 → 퇴거 단독 리포트 |
| 계약 만료 30일 전 퇴거 알림 (FR-13) | 집 등록 시 자동 예약, 내 집 → 퇴거 알림 |
| 원본 검증 (FR-18) | 리포트 또는 내 집 → 원본 검증 |
| 비밀번호 재설정, 집 정보·임대인 연락처 수정, 기록 보존 기간 | 로그인, 내 집 |
| AI 하자 태깅 (FR-06, OpenAI, `supabase/functions/vision`) | 촬영 직후 태깅 화면. 함수가 없거나 실패하면 원본만 고정하고 직접 표시 안내 |
| 구역별 예시 구도 사진 | 카메라 오른쪽 위 |
| 임대인 응답 실시간 알림 (Supabase Realtime) | 앱 위쪽 배너, 누르면 알림 화면 |
| 계약서 사진으로 집 정보 채우기 | 집 등록 → 계약서 사진으로 채우기 (로그인 필요) |

## 실제로 동작하는 것

- 앱 카메라 촬영(`expo-camera`). 갤러리 업로드는 제공하지 않습니다.
- 촬영한 사진 바이트의 SHA-256 해시(`expo-crypto`, `expo-file-system`의 `File`)와 단계별 해시 체인(`chain = sha256(prev + photoHash)`, 시작값은 0 64개)
- 카메라 권한이 없거나 웹 미리보기처럼 카메라를 쓸 수 없으면 "샘플 사진"으로 같은 흐름을 시연할 수 있습니다. 샘플은 이미지 대신 `sample:구역:단계:시각` 문자열의 해시를 씁니다.

## 모의(mock) 처리

- AI 하자 태깅(데모 모드만): 구역별로 정해진 결과를 돌려줍니다(벽지 곰팡이, 바닥 스크래치, 퇴거 시 벽지 찢김·욕실 곰팡이).
- 서버 해시와 서버 수신 시각: 기기 해시와 같은 값, 기기 시각 + 300ms
- 임대인 응답: 리포트 탭의 "임대인 화면으로 보기 (시연)"에서 확인 또는 이의를 남깁니다.
- 결제: 0.9초 뒤 성공 처리합니다. 실제 결제 SDK는 연결하지 않았습니다.
- 데이터는 메모리에만 있어서 앱을 다시 시작하면 처음 상태로 돌아갑니다.

## 화면 구조 (expo-router)

| 경로 | 화면 |
|---|---|
| `/` | 로그인 (아무 아이디와 비밀번호로 로그인, 가입하기 → 집 등록) |
| `/home` | 홈 대시보드 (탭) |
| `/records` | 기록: 입주·거주 중·퇴거 전환, 필터, 구역 추가 (탭) |
| `/reports` | 리포트 문서함 (탭) |
| `/myhome` | 내 집: 여러 집 전환, 새 집 추가, 로그아웃 (탭) |
| `/capture` | 빠른 촬영 시트 (탭 바 가운데 버튼) |
| `/camera` | 카메라 (`stage`, `zone` 파라미터) |
| `/tagging` | 하자 태깅 확인 (사진을 눌러 태그 추가) |
| `/zone/[id]` | 구역 상세 (입주·거주 중·퇴거 한눈에) |
| `/defect-report` | 거주 중 하자 신고 |
| `/notifications` | 알림 |
| `/certificate` | 입주 상태 확인서 미리보기 |
| `/share` | 임대인 공유 시트 |
| `/landlord` | 임대인 확인 화면 (웹 링크 시연) |
| `/compare` | 비교 결과 (퇴거 사진이 없으면 샘플로 채우기 제공) |
| `/payment` | 리포트 결제 (`key=compare` 또는 `only`) |
| `/lease-register` | 집 등록 |

## 파일 구성

- `src/theme.ts`: 색상 토큰과 폰트 (Figma 변수와 같은 값)
- `src/store.tsx`: 메모리 상태, 시드 데이터, 모의 AI
- `src/hash.ts`: 사진 해시와 해시 체인
- `src/ui.tsx`: 공용 컴포넌트 (버튼, 칩, 카드, 헤더, 시트, 태그 사진)
- `src/app/`: 화면 라우트
