# 자취실록

세입자가 입주·거주·퇴거 시점의 방 상태를 **위변조할 수 없는 기록**으로 남기고, 임대인 확인과 퇴거 비교 리포트로 보증금 분쟁을 줄이는 모바일 서비스입니다.

## 핵심 흐름

1. **집 등록**: 주소, 계약 기간, 보증금, 임대인 연락처를 입력합니다. 계약서 사진을 찍어 자동으로 채울 수도 있습니다.
2. **입주 기록**: 구역(현관, 벽지, 바닥, 욕실 실리콘, 창틀, 옵션 가전)별로 앱 카메라로만 촬영합니다. 촬영 즉시 SHA-256 해시와 서버 수신 시각으로 원본을 고정하고, AI가 하자 위치를 표시합니다.
3. **임대인 확인**: 입주 상태 확인서를 카카오톡, 문자, 링크로 보냅니다. 임대인은 앱 설치 없이 웹 링크에서 사진을 보고 확인하거나 이의를 남기며, 세입자 앱에는 실시간 알림이 뜹니다.
4. **거주 중 기록**: 새로 생긴 하자를 신고하고 기록으로 남깁니다.
5. **퇴거 기록과 리포트**: 입주 사진을 반투명하게 겹쳐 같은 구도로 촬영하고, 입주와 퇴거를 비교한 리포트(PDF)를 발급합니다.
6. **원본 검증**: 누구나 사진 파일의 해시로 기록이 원본인지 확인할 수 있습니다.

## 기술 구성

```
┌──────────────────────┐      ┌───────────────────────────────────────┐
│ Expo 앱 (app/)       │      │ Supabase (supabase/)                  │
│  · iOS / Android     │ ───▶ │  · Auth (이메일)                       │
│  · 웹 (임대인 링크)   │      │  · Postgres + RLS, 해시 체인 트리거     │
│                      │ ◀─── │  · Storage `originals` (수정·삭제 불가) │
│                      │      │  · Realtime (임대인 응답 알림)          │
│                      │      │  · Edge Function `vision` ─▶ OpenAI    │
└──────────────────────┘      └───────────────────────────────────────┘
```

- 앱: Expo SDK 57, React Native 0.86, expo-router, TypeScript
- 백엔드: Supabase (Postgres, Storage, Auth, Realtime, Edge Functions)
- AI: OpenAI Responses API (하자 태깅, 계약서 읽기). API 키는 Supabase 시크릿에만 둡니다.

## 빠른 실행

```bash
cd app
npm install
npx expo start
```

휴대폰의 Expo Go(SDK 57 지원 버전)로 터미널에 뜨는 QR 코드를 찍으면 실행됩니다. 서버 설정 없이도 로그인 화면의 "로그인 없이 둘러보기"로 데모 데이터를 써 볼 수 있습니다. 실제 계정과 서버 저장을 쓰려면 [app/README.md의 Supabase 설정](app/README.md#supabase-설정)을 따라 주세요.

## 현재 한계

프로토타입이라 아래 항목은 아직 구현하지 않았습니다.

- 결제: 9,900원 리포트 결제는 모의 처리입니다. 실제 PG를 연결하지 않았습니다.
- 서버 측 해시 재계산: 서버는 앱이 보낸 해시를 저장하고 체인을 계산하지만, 업로드된 파일을 다시 읽어 해시를 대조하지는 않습니다.
- 로그인: 이메일 로그인만 지원합니다. 카카오, Apple 로그인은 없습니다.
- 임대인 링크 호스팅: 웹 빌드를 직접 호스팅하고 `EXPO_PUBLIC_WEB_URL`을 지정해야 링크가 실제로 열립니다.
- 촬영 위치(GPS) 저장, 오프라인 촬영 대기열, 영상 워크스루, 분쟁 대응 문서는 없습니다.
- 퇴거 알림(로컬 알림)은 Expo Go에서 동작하지 않고, 개발 빌드나 스토어 빌드에서만 동작합니다.
